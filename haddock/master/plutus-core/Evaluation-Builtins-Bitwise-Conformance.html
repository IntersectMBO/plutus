data Check Source #

A property check expressed without performing it. Normal QuickCheck suites interpret it as an assertion, the Hedgehog suites have their own interpreter, and the test generator extracts its terms, first checking with checkHolds that the reference implementation satisfies the property for the sampled input.

generateBitwisePropertyFiles ∷ OutputFormat → CheckMode → FilePath → Int → QCGen → PropertyId → String → Gen Check → IO Generated Source #

Sample Hedgehog generators directly, with seeds derived from the executable's QuickCheck seed. No property runner or assertions are involved. Discarded inputs are retried, and the lazy stream stops at the requested case count. Equality cases retain both terms, numbered together with -A/-B suffixes.
