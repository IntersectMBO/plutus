### Added

- The `bls12_381_poseidonPermutation` builtin (CIP "Poseidon Permutation Built-in for Plutus"): the Poseidon permutation over the BLS12-381 scalar field, selecting a parameter set from an append-only variant registry (0 = midnight-zk, 1 = the circom BLS12-381 port). Costing is not implemented yet, so the builtin cannot be used on-chain.
