### Changed

- Replaced the placeholder costing of `multiIndexArray` ([CIP-0156](https://cips.cardano.org/cip/CIP-0156)) with a benchmarked cost model: CPU linear in the number of indices, memory linear in the length of the result. `multiIndexArray` now fails if given more than 4096 indices, because beyond that its execution time is not predictable from the index count alone.
