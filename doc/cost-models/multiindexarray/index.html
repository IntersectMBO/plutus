MultiIndexArray Cost Model Visualization

Interactive visualization of benchmark data and fitted cost model for the MultiIndexArray builtin function. This function looks up a list of indices in a Plutus array; the cost depends on the number of indices and not on the array size. Points are coloured by array size, so that independence is visible directly: every colour lies on the same curve. The number of indices is limited, because beyond that limit the execution time is not predictable from the index count alone; the panels below show the per-index cost across the range and its distribution.

Per-index cost across the range

Net time per index with the model's per-call constant subtracted, (t − overhead − c0) / indexCount. In the total time the constant swamps the per-index cost, so its rise across the range is only visible here; the model's charge per index is c1 + c2 · indexCount, a straight line. Small index counts are omitted: there the constant dominates the total, and dividing the small remainder by the count amplifies noise.
