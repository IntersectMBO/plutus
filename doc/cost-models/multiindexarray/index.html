MultiIndexArray Cost Model Visualization

Interactive visualization of benchmark data and fitted cost model for the MultiIndexArray builtin function. This function looks up a list of indices in a Plutus array; the cost depends on the number of indices and not on the array size, so the model surface in the 3D view is flat along the array-size axis. The number of indices is limited, because beyond that limit the execution time is not predictable from the index count alone; the histogram below shows the per-index time distribution.
